Troubleshooting
  • Cannot connect: check the MCP URL and that ASO is running. For local development, use the backend URL rather than Angular’s port 4200.
  • Login or redirect fails: ask your administrator to check the registered Codex callback and listener port. If the port is already in use, close the other login attempt and retry.
  • Wrong account or expired login: sign out of Codex’s MCP connection and the provider’s browser session, then sign in again and check identity.
  • ASO or search is unavailable: tell the agent to continue local work and report the limitation.
  • A write times out: retain the original request or event ID, check current state, and follow the error before retrying.
