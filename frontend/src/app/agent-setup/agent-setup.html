Troubleshooting and compatibility

  • Cannot connect: check the backend URL and server. Port 4200 serves Angular; it is not the configured MCP resource.
  • Login or redirect fails: check the exact callback, listener port, issuer, client ID and resource audience. Local registrations use code flow and PKCE.
  • Wrong identity or expired login: log out of the MCP client and IdP session, then sign in again and call identity. Do not share tokens or browser cookies. If Codex reports invalid_scope during local token refresh, run its login command again and recheck identity.
  • Search degraded: use available exact and keyword matches without claiming semantic coverage. If ASO is unavailable, say so and continue local work.
  • Uncertain write: retain the original request or event ID, read current state, and follow the error before retrying.

Simulated workflows: Claude Code-style and Cursor-style sequences are replayed with MCP Jam CLI. Native Claude Code and Cursor compatibility is unverified.

OAuth limit: local HTTP loopback and Keycloak’s audience mapper are verified for the stated clients; they do not establish strict HTTPS or RFC 8707 conformance. Verify another IdP separately.
