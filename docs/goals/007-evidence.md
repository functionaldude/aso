## Authorization review matrix

| Actor / channel | Ordinary reads | Own writes | Other person's edits | Acceptance | Moderation |
| --- | --- | --- | --- | --- | --- |
| Anonymous browser / no bearer | Public shell/setup/info/health only; product API 401 | 401/CSRF refusal | 401 | 401/CSRF refusal | 401/CSRF refusal |
| Signed-in member browser | Visible product data | Allowed with CSRF | 403 | Only own question with CSRF | 403 |
| Signed-in admin browser | Visible and explicit admin views | Allowed with CSRF | Explicit admin moderation action | Any question with CSRF | Explicit admin action with CSRF |
| Member/admin MCP bearer | Visible product data under resource audience | Permitted domain tools under own identity | 403, including admin bearer | No tool; REST session boundary denies | No tool; REST session boundary denies |
| Expired/wrong-audience/nonmember credential | No product data | Denied | Denied | Denied | Denied |

The matrix is enforced by [SecurityConfiguration](../../backend/src/main/kotlin/com/functionaldude/aso/identity/SecurityConfiguration.kt), [IdentityService](../../backend/src/main/kotlin/com/functionaldude/aso/identity/IdentityService.kt), and shared feature services, with real-credential assertions in [identity](../../backend/src/integrationTest/kotlin/com/functionaldude/aso/IdentityIntegrationTest.kt), [question](../../backend/src/integrationTest/kotlin/com/functionaldude/aso/QuestionIntegrationTest.kt), and [packaged browser](../../backend/src/e2eTest/kotlin/com/functionaldude/aso/PackagedApplicationE2ETest.kt) tests. Browser acceptance and moderation require a session, CSRF token and service-level owner/admin check; their tools do not exist on MCP. The 256 KiB request filter and typed content policy enforce payload and recognizable-credential limits without logging raw bodies; prior goal 002/003 evidence records their cases. The new [rate-limit integration test](../../backend/src/integrationTest/kotlin/com/functionaldude/aso/RateLimitIntegrationTest.kt) crosses browser REST and MCP with one user budget, independent Bob capacity, REST and MCP write 429/`Retry-After`, and retry of the rejected payload.
